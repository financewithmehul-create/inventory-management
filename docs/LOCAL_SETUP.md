# Running and testing the ERP on your own computer

This guide runs the **backend** (PHP, Laravel, the database) and the **frontend** (the screens, built with
Filament, Livewire and Tailwind) on your laptop, and shows how to test both. It works on Windows, macOS and Linux.

The screens are generated by the PHP app, so there is one app to run, plus a build step for its styles.

---

## 1. Install the tools (once)

| Tool | Version | Easiest way |
| --- | --- | --- |
| PHP | 8.3 | **Windows/macOS:** install **Laravel Herd** (free, includes PHP and Composer). **Linux:** your package manager. |
| PHP extensions | `bcmath`, `curl`, `fileinfo`, `gd`, `intl`, `mbstring`, `openssl`, `pdo_mysql`, `tokenizer`, `xml`, `zip` | Herd has them. On Linux install `php8.3-bcmath php8.3-curl php8.3-gd php8.3-intl php8.3-mbstring php8.3-mysql php8.3-xml php8.3-zip`. |
| Composer | 2.x | Included with Herd, or see getcomposer.org |
| Node.js | 20 or newer | nodejs.org (LTS) |
| MySQL or MariaDB | 8.0 / 10.6+ | **Windows:** Laragon or XAMPP. **macOS:** Herd Pro or DBngin. **Linux:** `sudo apt install mariadb-server` |
| Git | any | git-scm.com |

Check them:

```bash
php -v && composer -V && node -v && git --version
php -m | grep -iE "bcmath|intl|gd|pdo_mysql|zip"
mysql --version
```

## 2. Get the code

```bash
git clone https://github.com/financewithmehul-create/inventory-management.git
cd inventory-management
git checkout claude/zen-curie-pt2356
```

## 3. Create the database

Open a MySQL prompt (`mysql -u root -p`, or phpMyAdmin in XAMPP/Laragon) and run:

```sql
CREATE DATABASE erp CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
CREATE DATABASE erp_test CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
```

`erp` is for you to use. `erp_test` is a separate database for the automatic tests, because the tests erase
whatever database they run on.

## 4. Install the backend

```bash
composer install
cp .env.example .env        # Windows PowerShell: copy .env.example .env
php artisan key:generate
```

Open `.env` in an editor and set (remove the `#` at the start of these lines):

```ini
APP_URL=http://127.0.0.1:8000
APP_TIMEZONE=Asia/Kolkata
APP_CURRENCY=INR

DB_CONNECTION=mysql
DB_HOST=127.0.0.1
DB_PORT=3306
DB_DATABASE=erp
DB_USERNAME=root
DB_PASSWORD=          # your MySQL root password, may be empty on Laragon/XAMPP
```

Install the ERP with your own admin login and the India defaults:

```bash
php artisan erp:install --force --country=IN --currency=INR \
  --admin-name="Your Name" --admin-email=you@example.com --admin-password="ChooseAStrongOne"
```

On Windows PowerShell put the command on one line (no `\`).

Install every module (or leave some out):

```bash
# macOS / Linux / Git Bash
for p in accounts accounting barcode blogs contacts employees inventories invoices maintenance manufacturing payments products projects purchases recruitments sales time-off timesheets website; do php artisan $p:install --no-interaction; done
```

```powershell
# Windows PowerShell
"accounts accounting barcode blogs contacts employees inventories invoices maintenance manufacturing payments products projects purchases recruitments sales time-off timesheets website".Split(" ") | ForEach-Object { php artisan "$($_):install" --no-interaction }
```

## 5. Install and build the frontend

```bash
npm ci
npm run build
```

## 6. Run it

**Simple (one terminal):**

```bash
php artisan serve
```

Open **http://127.0.0.1:8000/admin** and sign in with the email and password from step 4.

**Full developer mode** (backend + background queue + log viewer + live-reloading styles, all in one command):

```bash
composer run dev
```

Use this while changing the code. Stop it with `Ctrl+C`.

If you use Laravel Herd, put the project folder in Herd's sites and open `http://inventory-management.test/admin`
instead.

## 7. What to click through

- **Inventory:** Products, Warehouses, Receipts (incoming), Deliveries (outgoing), Stock quantities.
- **Purchase:** create a vendor and a purchase order, confirm it, receive the goods.
- **Sales:** create a customer and a sale order, confirm, deliver, invoice.
- **Invoices / Accounting:** register a payment.
- **Settings:** turn optional features on or off (lots and serial numbers, packages, multi-step routes, variants).

## 8. Run the automatic tests

### Backend tests (Pest)

1. Create the test environment file `.env.testing` (it is ignored by git):

```ini
APP_ENV=testing
APP_KEY=base64:copy-the-APP_KEY-line-from-your-.env
APP_TIMEZONE=UTC
DB_CONNECTION=mysql
DB_HOST=127.0.0.1
DB_PORT=3306
DB_DATABASE=erp_test
DB_USERNAME=root
DB_PASSWORD=
```

2. Run them:

```bash
php artisan test --compact                       # everything, about 10 minutes
php artisan test --compact --filter=Inventory    # only tests with "Inventory" in the name
vendor/bin/pest --parallel --processes=4         # faster, uses several CPU cores
```

There are about 2,560 tests. All of them should pass. They create their own data inside `erp_test`.

### Browser tests (Playwright)

These open a real browser, sign in and click through the admin screens. The app must be running (step 6).

```bash
cd tests/e2e-pw
npm ci
npx playwright install chromium
```

The tests sign in as `admin@example.com` with password `admin123`, so create that user once:

```bash
cd ../..
php artisan erp:install --force --country=IN --currency=INR --admin-name=Admin --admin-email=admin@example.com --admin-password=admin123
```

(Do this on a throw-away database, never on real data.) Then:

```bash
cd tests/e2e-pw
npx playwright test --headed
```

## Common problems

| Problem | Fix |
| --- | --- |
| `Class "bcmath"` / "Call to undefined function bccomp()" | Enable the PHP `bcmath` extension and restart. |
| Page has no styling | Run `npm run build` (or `composer run dev`). |
| `SQLSTATE[HY000] [1045] Access denied` | Wrong `DB_USERNAME` / `DB_PASSWORD` in `.env`. |
| `SQLSTATE[HY000] [1049] Unknown database` | Create the database from step 3. |
| `No application encryption key` | Run `php artisan key:generate`. |
| Port 8000 already used | `php artisan serve --port=8001` |
| Changed `.env` but nothing changes | `php artisan config:clear` |
| Tests wipe my data | Tests must use `.env.testing` with the `erp_test` database. |
